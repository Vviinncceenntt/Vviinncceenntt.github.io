### Highlights of what was implemented
- **Calculator** — every Excel formula (`Rmin`, `Rmax`, `ERmin`, `ERmax`, `Lmax…`, `Nmin`, `Nmax`, `T_i`, `T_p`, `T_n`) translated to numerically-stable JS with `logFactorial` (safe up to n=5001). Verified by a Node sanity test.
- **Onboarding** — "I Agree" checkbox → "I Accept" button (disabled until agreed); fires `Haptics.selectionAsync`; detects OS; calls RevenueCat; uses `setMonth` to compute "expiring within 1 month" reminder with **OK** + **Extend Subscription** buttons; offline → enter the app so user can restore later.
- **Paywall** — only opens after RC reports inactive/expired (GDPR-compliant); annual auto-renew; price string read live from `pkg.product.priceString` (never hard-coded); store-specific cancel-policy copy chosen via `Platform.OS`.
- **Dashboard** — title + 5 sections + footnote; horizontal/vertical swipe paging via `FlatList` in RN (axis follows orientation; landscape-right + upside-down are blocked); ~100 ms throttled inputs to avoid render storms.
- **Section 4 matrix** — frozen header column with proper subscripts (`<SubSym>` keeps first letters from wrapping); columns over `[max(6, p), 6144]` with signature-collapse; **two stacked diagonal `LinearGradient` layers** correctly reverse direction between light/dark; number colours chosen for legibility in both modes.
- **Bottom nav** — 4 destinations with inline SVG icons, Chinese-on-top-of-English line by line; opens four popup modals with **`✕` close buttons** (never the word "Close"), guaranteed visible in landscape via SafeArea + absolute positioning.
- **Tip overlay** — single global layer; tap-outside / re-tap dismisses; auto-flips to clear bottom navigation; tooltip bubbles above subsequent matrix rows (no clipping).
- **Settings** — light/dark switch, 3-state triangle orientation toggle (grayed-out on web), Restore Purchase, Reset, Manage Subscription deep-link to App Store / Google Play subscription page based on detected OS, version 1.0.0.
- **Legal** — 4-tab popup (PP / EULA / T&C / Disclaimer) loading remote pages with offline lipsum fallback and the "English only" bilingual notice.
- **Functions** — WebView/iframe of remote MathJax page with self-contained offline fallback (`assets/html/functions.html.js`) where every LaTeX backslash is **double-escaped** (`\\\\binom`) to survive bundler minification.
- **Asset pipeline** — `scripts/generate-assets.sh` performs SVG → vector PDF (sRGB) → 32-bit PNG for app icon (1024) and all six splash variants (2732). Placeholder 1×1 PNGs are committed so the build succeeds before you run the pipeline.
