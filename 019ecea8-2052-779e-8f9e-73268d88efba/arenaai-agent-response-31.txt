## Summary

### 1️⃣ Build error: `Cannot find module 'react-native-worklets/plugin'`

**Root cause:** Reanimated 4 (the version Expo SDK 54 pins) moved its babel plugin into a separate `react-native-worklets` package — but it doesn't list it as a regular `dependencies` entry, only as a peer. So `npm install` doesn't fetch it, and `react-native-reanimated/plugin/index.js` (whose first line is `require('react-native-worklets/plugin')`) crashes.

**Fix:**
- Added `"react-native-worklets": "0.5.1"` to `package.json` (the version SDK 54 pins in `bundledNativeModules.json`).
- Changed `babel.config.js` to load `react-native-worklets/plugin` directly (the modern canonical name).
- Added Expo-Go detection (`Constants.appOwnership === 'expo'`) in `DashboardScreen.js` so the native `PagerView` is **not even loaded** in Expo Go (where its native view would crash the bridge). Expo Go now cleanly falls back to a single vertical ScrollView; native PagerView swipe is restored when you do `eas build --profile development`.

**To recover:**
```bash
cd mobile
rm -rf node_modules package-lock.json
npm install                 # picks up react-native-worklets@0.5.1
npm run start
```

Verified in a clean sandbox: **664 packages, ~53 s, no warnings, no deprecations**.
