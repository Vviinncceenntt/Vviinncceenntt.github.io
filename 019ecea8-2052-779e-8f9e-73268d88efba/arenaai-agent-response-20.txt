Port 8000 is already taken by another process (the Chinese error means "permission denied accessing socket" — Windows shows that when a port is reserved or in use). Easy fix: just pick a different port.

## Try this

```bash
cd /c/path/to/swiss-round-calculator/web
python -m http.server 8765
```

Then on iPhone Safari:
```
http://192.168.0.127:8765
```

Use any port in the **8000-9999** range that isn't `8081` (Metro) or `8000` (the blocked one). `8765`, `9000`, `8888`, `5500` all typically work.

## If multiple ports fail with the same error

It means Windows has **reserved a port range** (common after Hyper-V / WSL / Docker is enabled — they grab 1000s of ports). Check what's reserved:

```bash
netsh interface ipv4 show excludedportrange protocol=tcp
```

You'll see something like:
```
Start Port    End Port
----------    --------
     50000       50059
      8000        8099
```

Pick a port **outside** every range listed (e.g. `45678`).

## Permanent quick alternative — Node's `serve`

If Python keeps fighting you:

```bash
npx serve /c/path/to/swiss-round-calculator/web -l 8765
```

(First run installs `serve` — type `y` when prompted.) Same result, different tool.

## Also: open the firewall for the chosen port

Windows Defender Firewall may block inbound 8765 just like it did 8081. In **PowerShell as Administrator**:

```powershell
New-NetFirewallRule -DisplayName "Local web preview 8765" -Direction Inbound -Protocol TCP -LocalPort 8765 -Action Allow -Profile Any
```

(Replace `8765` with whichever port you ended up using.)
