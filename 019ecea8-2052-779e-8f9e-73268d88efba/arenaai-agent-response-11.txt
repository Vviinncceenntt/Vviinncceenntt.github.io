## The "23-byte download" IS the working response

When you visit `http://192.168.x.x:8081/status` from Safari on your iPhone, Metro sends back the literal text `packager-status:running` (which is exactly 23 bytes). Safari sees:

- `Content-Type: application/octet-stream` (Metro doesn't label it as plain text)
- No HTML structure

…so instead of displaying it, Safari treats it as a file download. **The bytes flowing means the network path is open.** Firewall ✓, AP isolation ✓, IP correct ✓.

Don't worry about opening the file — it's just `packager-status:running` as raw text.

## So now: load the actual app

Your iPhone CAN reach the dev server. To load the calculator:

### On Windows (PC):
```bash
cd C:\path\to\swiss-round-calculator\mobile
npx expo start --lan --clear
```

Wait until you see the QR code AND a line like:
```
› Metro waiting on exp://192.168.x.x:8081
```

### On iPhone:
1. Open the **Camera app** (not Expo Go directly).
2. Point at the QR code on your PC screen.
3. A yellow banner appears at the top saying something like **"Open in Expo Go"**.
4. **Tap that banner.**

The phone will switch to Expo Go and start downloading the bundle. **Be patient on first load — expect 30 to 90 seconds.** A progress bar should fill from 0% to 100%.

## What to watch in the cmd window during the load

While the iPhone is loading, the PC's Metro window will print things like:

```
iOS Bundling complete 27451ms
LOG  Running "main" with {...}
```

If you see those, **the app loaded successfully** even if the phone still shows a white screen for a few more seconds.

## If the bundle stops at 0% or partway

That would be a different problem (usually a JS syntax error or a missing module). Tell me:
1. What % the loading bar reaches
2. Any red/yellow error overlay on the phone
3. Any error lines in the Windows cmd window

…and I'll diagnose from there.

## If the bundle hangs at 99%

That's typically Metro waiting for `metro-cache` to finish writing on Windows. Wait one more minute, then try shaking the phone (or pulling down from the top in Expo Go) and tapping **Reload**.
