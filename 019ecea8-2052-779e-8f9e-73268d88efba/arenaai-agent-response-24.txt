## Section A — Network OK but font still missing on Safari

Python's `http.server` may serve TTF/WOFF2 with a wrong `Content-Type`, and Safari is **stricter than Chrome about font MIME types**. Quick test: visit

```
http://192.168.0.127:8765/index.html
```

…then in the Web Inspector on iPhone (see "Enabling Inspector" below) check the Console for messages like:

```
Failed to decode downloaded font
OTS parsing error: invalid version tag
```

If you see those, it's the MIME issue. **Fix without enabling MIME types**: just use `npx serve` instead of Python — it sets the right headers automatically:

```bash
cd /c/path/to/swiss-round-calculator/web
npx serve . -l 8765 --cors
```

(First run installs `serve`; type `y` when prompted.) Restart Safari, refresh — fonts should appear.

### Or fix Python itself
Create a tiny helper script `web/serve.py` that registers font MIME types:

Then in Git Bash:

```bash
cd /c/path/to/swiss-round-calculator/web
python serve.py
```

This wraps `http.server` with the right MIME types, forces IPv4, and adds CORS headers — fonts will load correctly in Safari.

## Section C — 404 / wrong path

Check that `web/assets/fonts/ChironSungHK.ttf` and `web/css/fonts.css` exist (case-sensitive):

```bash
ls /c/path/to/swiss-round-calculator/web/css/fonts.css
ls /c/path/to/swiss-round-calculator/web/assets/fonts/
```

`fonts.css` references `../assets/fonts/X.woff2`, so from a request to `/css/fonts.css`, the relative path resolves to `/assets/fonts/X.woff2`. If the `assets` folder is mis-cased on disk (Windows is case-insensitive but the web server may still be case-sensitive in URL matching), Safari fails to load while Chrome's tolerant heuristics save it.

## Enabling iPhone Safari Web Inspector (for diagnosing)

If you want to see exactly what Safari complains about:

1. On iPhone: **Settings → Safari → Advanced → Web Inspector** → **ON**.
2. Connect iPhone to PC via Lightning/USB-C cable.
3. On Windows: Web Inspector requires a Mac for the desktop side. Alternative — use **Inspect.dev** (free trial), or just enable **Settings → Safari → Advanced → Show Develop menu** on iPhone, then tap the URL bar → bottom toolbar shows a 🔧 wrench icon → tap → **Show Web Inspector** lite view appears with a Console tab.
