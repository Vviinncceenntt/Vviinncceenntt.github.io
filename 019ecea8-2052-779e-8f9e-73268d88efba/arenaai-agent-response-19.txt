## ⭐ Option B — EAS Development Build (the proper long-term solution)

This builds a custom version of Expo Go containing **your project's exact native modules**, including `react-native-purchases`. Once installed on your iPhone you never deal with Expo Go's network handoff again.

### Steps (all from Git Bash on Windows):

```bash
cd /c/path/to/swiss-round-calculator/mobile

# 1. Fix login: use EMAIL, not username
npx expo login
# When prompted: enter your EMAIL address (the one you registered with), not username
# If you forgot the password: https://expo.dev/forgot-password

# 2. Install EAS CLI globally
npm install -g eas-cli

# 3. Initialise EAS project (creates a project ID)
eas init

# 4. Build a development client for iOS (free; runs on Apple's cloud servers)
eas build --profile development --platform ios
```

During step 4, EAS asks:
- **Apple account email**: any Apple ID works (free, no $99 developer account needed for development builds)
- **Bundle identifier**: accept the default `com.vviinncceenntt.swissroundcalculator`
- **Provisioning**: pick "**Let EAS handle credentials**"

Build runs ~15 minutes in the cloud. When done, EAS prints a URL and QR code. On your iPhone:
1. Open the URL in Safari → "Install" → asks for device passcode
2. The app installs as `Swiss Round Calculator (Dev)` on your home screen
3. Once installed, run on PC: `npx expo start --dev-client --lan --clear`
4. Open the dev client app on iPhone — it auto-discovers your PC via Bonjour AND has a built-in URL entry field

Subsequent code changes only require step 3+4. Build only happens again if you change native modules.

### About the assertion crash

The `Assertion failed: !(handle->flags & UV_HANDLE_CLOSING)` is a Node.js 24 crash bug triggered by Expo's CLI when login fails. Not your fault, not fatal — just an ugly crash on top of the actual error. Node 24 has several outstanding bugs interacting with older CLI tooling. You can downgrade to Node 22 LTS to avoid these, but it's optional:

1. Download Node 22 LTS from <https://nodejs.org/en/download/lts>
2. Install (uninstalls Node 24 automatically)
3. Re-run `npm install` in `mobile/`
