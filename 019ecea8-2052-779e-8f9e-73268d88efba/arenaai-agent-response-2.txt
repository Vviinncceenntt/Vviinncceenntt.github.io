## Summary of changes

### 1️⃣ `mobile/scripts/generate-assets.sh` — Git Bash on Windows
- Now **auto-detects** Inkscape (incl. typical `C:\Program Files\Inkscape\bin\inkscape.exe`), `rsvg-convert`, `magick`/`convert`, and `gs`/`gswin64c`/`gswin32c`.
- Three fallback paths: `SVG → PDF → PNG` (preferred) or direct `SVG → PNG` via Inkscape or ImageMagick.
- Prints a clear tool-detection table and an install-recommendation block if nothing is available.
- On Git Bash for Windows, installing only **ImageMagick** is now enough — no need for librsvg.

### 2️⃣ Tooltips no longer clipped by following sections
- Replaced per-anchor absolute-positioned bubbles with **one fixed-position bubble** mounted directly under `<body>`. Because it uses `position: fixed`, the `card` containers (`overflow` / stacking contexts) can no longer clip it.
- The overlay flips above the anchor when it would otherwise sit within 84 px of the bottom navigation.
- Re-positions on scroll/resize while open; closes on outside-tap and on second tap of the same anchor.

### 3️⃣ Live `<r>`, `<p>`, `<n>` interpolation in Sections 2 & 3
- New `interp(str, ctx)` runs on every tooltip open AND every render, replacing `<p>`, `<n>`, `<r>` (and HTML-encoded `&lt;p&gt;` etc.) with the current input values.
- The tooltip dictionary stores the **raw template** (`<p>`/`<n>`/`<r>`) so substitution always uses the freshest values from `lastCtx()`.

### 4️⃣ "Varies with Top (p=…) Placements" → tooltip of Section 4 title
- The explicit subtitle text is removed from `index.html`.
- Section 4 title is now a `tip-anchor` (`<span id="matTitleAnchor">`) bound by `bindTip(...)` to deliver the bilingual description as a hover/tap tooltip with live `p` interpolation.

### 4️⃣b Matrix First-Column descriptions no longer overflow
- The `th.head-col` is now **hard-bounded** (`width / min-width / max-width: 140 px`; 120 px on mobile) with `white-space: normal; word-break: keep-all; overflow-wrap: anywhere;` so:
  - Chinese characters stay grouped (no mid-line breaks).
  - Long English wraps cleanly within the cell.
  - Tooltip descriptions never spill into the body cells.
- Notation tokens (`Rmin`, `LmaxNmax`, …) keep `white-space: nowrap` so the first letter never floats to the next line.

### 5️⃣ Real toggle switches for Theme & Orientation Lock (with Light/Dark zh-on-top-of-en)
Both web AND React Native:

| Setting           | Control                                                                              |
|-------------------|--------------------------------------------------------------------------------------|
| **Theme**         | Rectangular toggle switch with **淺色 / Light** on the left, **深色 / Dark** on the right (each option Chinese above English) |
| **Orientation Lock** | 3-option segmented toggle: **自動 / Auto**, **橫向（左）/ Landscape Left**, **直向 / Portrait** (each option Chinese above English; grayed-out on web) |

- Web: dedicated `.toggle-switch` (rectangular track + circular knob) and `.orient-toggle` segmented group — both styled to follow theme variables.
- Mobile: native `<Switch>` for Theme and a custom segmented `OrientToggle` component for orientation.
