Two problems combined here:

1. **Ports 8081 and 8082 are still held by zombie Node processes** from your earlier failed attempts — that's why Expo keeps falling back to 8083.
2. **The 8083 QR code has degraded finder patterns** because some terminals render Unicode block characters slightly off when the URL grows past a certain length, and the camera can't decode it.

Two easy fixes — do **either one**:

## Fix A — Kill the zombie processes, get port 8081 back

In a new `cmd` window:

```bash
netstat -ano | findstr :8081
netstat -ano | findstr :8082
```

You'll see lines like:
```
TCP    0.0.0.0:8081    0.0.0.0:0    LISTENING    14628
```
The number at the end (`14628`) is the **PID** (process ID). Kill each one:

```bash
taskkill /F /PID 14628
taskkill /F /PID <whatever_pid_for_8082>
```

Then restart Expo — it will use 8081 again and the QR code will render normally:

```bash
cd C:\path\to\swiss-round-calculator\mobile
npx expo start --lan --clear --port 8081
```

## Fix B — Skip the QR code entirely, type the URL into Expo Go

This works regardless of how mangled the QR code is.

1. In your PC's `cmd` window, look for the line printed just above the QR code:
   ```
   › Metro waiting on exp://192.168.x.x:8083
   ```
   Note the full URL: `exp://192.168.x.x:8083` (with **your** real IP).

2. On your iPhone, open **Expo Go**.
3. On the home screen, find the **"Enter URL manually"** option (it may be labelled **"Open from Clipboard"** or shown as a text field at the top, depending on Expo Go version).
4. Type or paste: `exp://192.168.x.x:8083`
5. Tap **Connect** / **Open**.

That bypasses the QR code completely.

## Fix C — Make the terminal render bigger / cleaner QR codes

If you must use a high port and the QR code still won't scan from the screen:

1. In your `cmd` window, press the title bar → **Properties** → **Font** → set size to **20 or larger**.
2. Or right-click the cmd window → **Properties** → **Layout** → set **Screen Buffer Width** to 120 and **Window Width** to 120 — Expo will print the QR larger.
3. Or simply **zoom your screen** with Ctrl+Scroll while the QR is showing.

The finder squares should reappear clearly.

---

## My recommendation

**Do Fix A first** (kill the zombies, free port 8081). It's the root cause. Once Metro is back on 8081 you'll have:
- Normal QR code with proper corner markers
- Shorter URL (less data → fatter QR pixels → easier to scan)
- No more `--port 8082/8083` confusion across reloads

Then scan with the **iPhone Camera app** as before.

If for any reason port 8081 stays stuck, fall back to **Fix B** — manually typing `exp://YOUR.IP:8083` into Expo Go works 100% of the time.
