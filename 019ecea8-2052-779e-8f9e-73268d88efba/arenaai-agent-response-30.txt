### Native-build heads-up

Items 5–8 (including PagerView swipe) require an **EAS dev client build** — Expo Go's bundled native modules don't include `react-native-pager-view`. In Expo Go you'll see the **fallback** (single vertical ScrollView) which still works, but doesn't snap section-to-section.

To test the real native swipe, run once (from Windows):

```bash
cd mobile
npm install         # picks up pager-view, gesture-handler, reanimated, screens
npx eas build --profile development --platform ios
```

EAS does the iOS build on Apple's cloud (no Mac needed); install the resulting `.ipa` on your iPhone, then `npm run start -- --dev-client` instead of `npm run start`. Subsequent JS-only changes don't need a rebuild.

In Expo Go itself, you'll see all v1.0.13 fixes EXCEPT the snap-paging (where it'll degrade to scrolling).

```
$ git tag
v1.0 … v1.0.13
```
