You're hitting the modern Expo Go UI which dropped the manual URL field — it relies on **Bonjour/mDNS auto-discovery** instead. That discovery often fails on Windows because Windows doesn't ship a mDNS responder. Three reliable ways around it, easiest first:

## ✅ Easiest: deep-link from Safari (no QR code, no manual entry)

1. On your PC, look at the `cmd` window where Expo is running. Find the line above the QR code:
   ```
   › Metro waiting on exp://192.168.x.x:8081
   ```
   (or `:8083` — whatever it says). Note the full URL.

2. On your iPhone, open **Safari** (not Expo Go).

3. Tap the URL bar and type **exactly** (no `http`, no spaces):
   ```
   exp://192.168.x.x:8081
   ```
   …using your **real** IP and the **real** port shown in your cmd window.

4. Press Go.

5. Safari will pop up a dialog **"Open this page in Expo Go?"** → tap **Open**.

That hands the URL directly to Expo Go, bypassing both the QR scanner and the mDNS discovery. It works 100% of the time.

## ✅ Permanent fix: install Apple's Bonjour service on Windows

Modern Expo Go finds your PC over the LAN via mDNS, the same protocol that AirPrint and AirPlay use. Windows doesn't ship a mDNS responder, so your dev server is invisible.

Install Apple's free **Bonjour Print Services for Windows** (it ships the mDNS responder daemon):

1. Download from <https://support.apple.com/kb/DL999>
2. Run the installer → restart your PC.
3. Restart Expo: `npx expo start --lan --clear`.
4. Your iPhone's Expo Go home screen will now list the dev server automatically — just tap it.

After this is installed once, every future project shows up automatically.

## ✅ Cleaner QR code option (if you still want to scan)

The "flat" QR is too small/dense. To fix:

1. Open the Expo Dev Tools page in your computer's browser:
   ```
   http://localhost:8081
   ```
   (it's already running when `expo start` is active).

2. The web page shows a **larger, properly-rendered QR code** with crisp finder squares. Camera app will scan it instantly.

If `http://localhost:8081` shows a blank page or "Bundling…", give it 10-20 seconds — Metro is preparing assets.
